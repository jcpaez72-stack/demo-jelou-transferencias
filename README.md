# Demo Jelou × Transferencias

Demo interactiva del cobro por transferencia con confirmación del banco en línea, sobre WhatsApp con Jelou.

- `index.html` — los 4 escenarios (Banco del Pacífico, Produbanco, Banco Guayaquil, Pago no llega)
- `pacifico.html` — abre directo en el escenario de Banco del Pacífico
- `produbanco.html` — abre directo en el escenario de Produbanco

Publicado con GitHub Pages desde la rama `main`, carpeta raíz.
